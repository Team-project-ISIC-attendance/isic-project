O nás ako tíme

Sme fullstack vývojový tím zložený z piatich študentov, ktorí sa spojili s cieľom vytvoriť inovatívne riešenie pre evidenciu dochádzky pomocou ISIC kariet. Každý člen tímu prináša svoje špecifické znalosti a skúsenosti, čo nám umožňuje pokryť všetky aspekty projektu od hardvéru cez backend až po frontend.

Náš tím sa stretáva pravidelne každý pondelok o 17:00 v miestnosti A514, kde diskutujeme o progrese, riešime výzvy a plánujeme ďalšie kroky. Komunikujeme prostredníctvom MS Teams

Projektové míľniky

1
Formovanie tímu a výber témy
Týždeň 1-2 (September 2025)
Tím sa stretol po prvýkrát, prediskutoval možné témy a jednomyseľne zvolil ISIC Attendance System. Rozdelili sme si role, definovali stakeholderov a vytvorili prvotný Product Backlog s hlavnými User Stories.
✓ Dokončené
2
Technický výskum a analýza
Týždeň 3-4 (Október 2025)
Komplexný výskum NFC modulov (PN532), embedded platforiem (ESP12-F), backend technológií (FastAPI + PostgreSQL) a frontend frameworkov (React + TypeScript). Vytvorené elektronické schémy, dátový model, UX toky a API kontrakty.
✓ Dokončené
3
Objednávka a montáž hardvéru
Týždeň 5-6 (Október 2025)
Finalizovaný Bill of Materials a objednané komponenty: ESP12-F, PN532 NFC modul, USB-TTL adaptér a príslušenstvo. Po doručení vykonaná montáž podľa schémy a prvotné testy napájania. Pripravené vývojové prostredia pre všetky vrstvy.
✓ Dokončené
4
Prvé čítanie ISIC kariet
Týždeň 7-8 (November 2025)
Dosiahnuté prvé úspešné čítanie ISIC kariet - UID sa číta správne cez MIFARE protokol. Prechod z RTOS na signal/slot architektúru s task schedulerom pre lepší výkon. Implementované základné API endpointy a frontend routing.
✓ Dokončené
5
MQTT komunikácia HW → Backend
Týždeň 9-10 (November 2025)
Úspešná implementácia MQTT klienta na ESP s task schedulerom. Backend prijíma správy cez MQTT broker a ukladá dochádzku do databázy. Dokončené CRUD operácie, registračný formulár a high-fidelity wireframes.
✓ Dokončené
6
Integrácia a stabilizácia
Týždeň 11-12 (December 2025 - Január 2026)
Implementovaná API autentifikácia a základná FE + BE integrácia. Počas vianočnej pauzy vykonaný research OTA aktualizácií a bug fixes. Riešenie problémov so stabilitou napájania hardvéru.
✓ Dokončené
7
Prvý funkčný prototyp
Týždeň 13 (Január 2026)
Dokončený prvý funkčný prototyp systému. Hardvér číta ISIC karty, backend spracováva dochádzku, frontend zobrazuje dáta. Prototyp pripravený na testovanie a iterácie na základe spätnej väzby.
✓ Dokončené
8
PDF dokumentácia projektu
Do 20. januára 2026
Príprava a odovzdanie kompletnej PDF dokumentácie projektu. Súhrn technických rozhodnutí, architektúry systému, použitých technológií a výsledkov testovania prvého prototypu.
✓ Dokončené
9
Multi-user systém a admin panel
Týždeň 14-15 (Január - Február 2026)
Rozšírenie systému o role-based prístup (admin, učiteľ). Implementovaný admin panel vo FE, HW konzola v BE a FE, nový JSON config formát pre HW so zníženou latenciou skenov (~40 %) a MQTT panel interakcia.
✓ Dokončené
10
HW monitoring a prechod na ESP32
Týždeň 16-17 (Február - Marec 2026)
Implementovaný MQTT status topic pre online/offline monitoring zariadení v BE a FE. Globálne testovanie odhalilo limitáciu ESP12-F pre WPA2 eduroam — systém migrovaný na ESP32. Opravené bugy v BE (kolízia skenov), FE (pridanie študenta, skratky) a kritický PN532 lib segfault v HW.
✓ Dokončené
11
Produkčné nasadenie na server STU
Týždeň 18-19 (Marec 2026)
Celý systém nasadený na server STU — BE, FE aj ESP32 zariadenia fungujú v produkčnom prostredí end-to-end. Opravené OTA aktualizácie (lokálne riešenie namiesto verejného API) a HW retry logika pri nestabilnom WiFi.
✓ Dokončené
12
Finálna dokumentácia a prezentácia
Týždeň 20-21 (Apríl - Máj 2026)
Dokončená kompletná PDF dokumentácia projektu (BE, HW, FE sekcie). Úspešná finálna prezentácia 20.05.2026 — predvedené live skenovanie ISIC kariet, OTA aktualizácia a celý end-to-end flow v produkčnom prostredí STU.
✓ Dokončené
